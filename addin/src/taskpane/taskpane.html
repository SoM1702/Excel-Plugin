Mathematical equations reference

1. Logit: z = ∑ wj·xj + b

2. Sigmoid: p = σ(z) = 1 / (1 + e-z)

3. Cross-entropy: J = -(1/m) ∑ [y ln(p) + (1-y) ln(1-p)]

4. Gradients: dw = (1/m) XT(p - y),   db = (1/m) ∑(p - y)

5. Update: w ← w - α·dw,   b ← b - α·db

See docs/LOGISTIC_REGRESSION_EQUATIONS.md for derivations and proofs.
